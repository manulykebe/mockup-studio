Scenario 1 - Open the combined Preparations overview

Given

  • a Signals GxP Experiment contains a Preparations Master table,
  • the Preparations Master table contains one or more Preparation Subtables,
  • and the Preparation Subtables contain preparation records.

When the User triggers the GxP Preparation Balance Measurement external action from the Preparations Master table

Then

  • the System shall open the Balance Interface UI,
  • the System shall display one combined preparations table containing all preparation records from all Preparation Subtables belonging to that Preparations Master table,
  • each preparation record shall be displayed once,
  • and records from Preparation Subtables outside the selected Preparations Master table shall not be displayed.

Scenario 2 - Identify the source and description of each preparation

Given the combined preparations table contains records from one or more Preparation Subtables

When the User views the combined preparations table

Then

  • the System shall display an additional column named "Source",
  • the "Source" value of each preparation record shall equal the name of the Preparation Subtable from which that record originates,
  • the System shall display a column named "Description",
  • the "Description" value of each preparation record shall equal the value from the "Description" column of its source Preparation Subtable,
  • and an empty source "Description" value shall be displayed as empty and shall not be replaced with another value.

Scenario 3 - Sort the combined preparations table

Given the combined preparations table contains records from multiple Preparation Subtables

When the User sorts a sortable column

Then

  • the System shall sort all records in the combined result set, not only the records on the current page,
  • the column shall support ascending and descending sorting,
  • and values shall be sorted according to their data type, including text as text, numbers as numbers and dates as dates.

Scenario 4 - Filter the combined preparations table

Given the combined preparations table contains records from multiple Preparation Subtables

When the User enters a filter value, including a value from the "Source" or "Description" column

Then

  • the System shall display only the matching preparation records from the combined result set,
  • the result count and pagination shall be updated to reflect the filtered result set,
  • and clearing the filter shall restore all preparation records from the combined result set.

Scenario 5 - Page through the combined preparations table

Given the number of preparation records exceeds the selected page size

When the User navigates through the combined preparations table

Then

  • the System shall provide page navigation and a page-size selector with options 5, 10, 25 and All,
  • the System shall display the current record range and the total number of records,
  • and each record in the combined or filtered result set shall be reachable through the pagination controls.

Scenario 6 - Load Preparation Subtables asynchronously

Given a Preparations Master table contains multiple Preparation Subtables

When the User opens the Balance Interface UI

Then

  • the System shall load the Preparation Subtables asynchronously,
  • the System shall show that data is loading until all Preparation Subtables have been processed,
  • the Interface shall remain responsive while the preparation records are loading,
  • and the completed result set shall contain each preparation record once, irrespective of the order in which the Preparation Subtables finish loading.

Scenario 7 - No preparations available

Given the Preparations Master table has no Preparation Subtables or its Preparation Subtables contain no preparation records

When the User triggers the GxP Preparation Balance Measurement external action from the Preparations Master table

Then the System shall open the Balance Interface UI and display an empty-state message without displaying an error.
