JGVT-4463 - Reports_Audit Trail: Experiment Audit Trail - User Interface - Custom Search Builder - Acceptance Criteria

Scope: applicable only to Experiments using a GxP-GMP template (Release 3.0.0 and Release 3.1.0).

Preconditions

  • Given the user has an active Signals session
  • And the user opens an Experiment Audit Trail page containing data

1) Custom Search Builder is available

Given the user is viewing an Experiment Audit Trail page containing data
When the user views the available search options
Then the user can open the Custom Search Builder

2) Add a search condition

Given the user has opened the Custom Search Builder
When the user selects an audit trail field, an operator and a value
Then the selected search condition is displayed in the builder
And the user can add conditions for the audit trail fields Date/Time, User Name, User ID, Entity Type, Entity Name, Action, Change Type, Details, Old Value, New Value and Event ID

3) Apply combined search conditions

Given the user has added two or more search conditions
When the user combines the conditions with AND or OR and applies the search
Then the audit trail table displays the records matching the configured conditions
And the result count and pagination reflect the filtered result set

4) Clear the Custom Search Builder

Given the user has applied Custom Search Builder conditions
When the user clears or removes the conditions
Then the audit trail table displays the unfiltered records again

5) No matching records

Given the user has applied Custom Search Builder conditions that match no records
When the user applies the search
Then no audit trail records are displayed
And the user is informed that no matching records were found

As a user,

I want to build advanced queries using multiple conditions on the Experiment Audit Trail, so that I can review specific GxP audit records efficiently.

The Custom Search Builder shall allow the user to select an audit trail field, choose a comparison operator, enter a value, and combine multiple conditions using AND or OR logic. The resulting query shall be applied to the Experiment Audit Trail table.

Scope

  • Provide access to the Custom Search Builder from the Experiment Audit Trail page.
  • Allow the user to create, edit and remove multiple search conditions.
  • Support AND and OR combinations between conditions.
  • Support searches on the available Experiment Audit Trail fields.
  • Apply the query and display only matching audit trail records.
  • Allow the user to clear the query and return to the unfiltered results.
  • Inform the user when no records match the query.

Out of scope

  • Export functionality, which is covered by JGVT-4462.
  • Changes to the audit trail data source.
  • Changes to existing sorting, pagination or basic search behavior.
