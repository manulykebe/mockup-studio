Preconditions

  • Given the user has an active Signals session
  • And the user has admin rights
  • And the user opens a System Audit Trail page for a selected Month and Year containing data

1) Export options

Given the user is viewing a System Audit Trail page containing data
When the user views the available actions
Then the user can see Copy (to clipboard as RTF), CSV, Excel, PDF controls.

2) Export content

Given the user is viewing a System Audit Trail page containing data
When the user selects an export control
Then the complete audit trail dataset for the selected month/year is copied or downloaded in the user's selected format
And the output includes all records across all categories (Notebook, Attributes, ADO, External Action, Data Source, System Group, Materials Definition, Roles, SO Properties, Security Policy, Templates, System Settings, Global Numbering, Users), not only the current page
And the output includes the "Source" column identifying the originating category of each record
And the exported content is identical to the audit trail table displayed on screen.

3) Filtered export

Given the user has applied a filter to the audit trail
When the user selects an export control
Then the output contains all records matching the user's filter
And the user is informed that the output is a filtered subset.

4) File name

Given the user is viewing a System Audit Trail page containing data for a selected Month and Year
When the user exports to CSV, Excel or PDF
Then the file is named {environment}.{yyyyMM}.system-audit-trail.iso8601(creation date).{ext}, (e.g. devinternal.202608.system-audit-trail.20260813T123456125+02:30.pdf)
And {ext} is csv, xlsx or pdf.

5) Access restricted to administrators

Given the user does not have admin rights
When the user attempts to access the System Audit Trail export options
Then the export controls and underlying data are not available to the user.
