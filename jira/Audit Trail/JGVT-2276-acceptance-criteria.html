Preconditions

  • Given the user has an active Signals session
  • And the user has admin rights
  • And the user navigates to the System Audit Trail page

1a) System audit trail search - button

Given the user has admin rights and navigates to the System Audit Trail page
When the user selects a Month and Year from the dropdown lists (e.g. August, 2026) and clicks "Search"
Then a button "Browse Audit Trail" to display the audit trail table becomes available for the selected month/year.

1b) System audit trail data is available - audit trail table

Given the button to display the audit trail table is available
When the user clicks the button "Browse Audit Trail"
Then a table with the audit trail data is displayed with columns: Source, Date/Time, User Name, User ID, Entity Type, Entity Name, Action, Change Type, Details, Old Value, New Value, Event ID
And the "Source" column identifies the originating category of the record (e.g. Notebook, Attributes, ADO, External Action, Data Source, System Group, Materials Definition, Roles, SO Properties, Security Policy, Templates, System Settings, Global Numbering, Users)
And a global search field is displayed above the table
And sortable column headers show sorting arrows
And pagination controls (page numbers, previous/next, page-size selector) are displayed below the table
And the content of the table is identical to the export (Excel, PDF).

2a) Search - matching records found

Given the audit trail table is displayed with data
When the user enters a search term that matches one or more rows
Then only the rows matching the search term are displayed
And the record count and pagination reflect the filtered result set.

2b) Search - no matching records

Given the audit trail table is displayed with data
When the user enters a search term that matches no row
Then a notification "No matching records found" is displayed.

3a) Sorting - ascending / descending per column

Given the audit trail table is displayed with data
When the user clicks a sortable column header
Then the table is sorted ascending by that column, indicated by the sort arrow
When the user clicks the same column header again
Then the table is sorted descending by that column, indicated by the sort arrow.

3b) Sorting - multi-column

Given the audit trail table is already sorted by one column
When the user shift-clicks a second sortable column header
Then the table is sorted first by the initial column and then by the second column, both indicated by sort arrows.

4a) Pagination - user page-size options

Given the audit trail table contains more rows than the current page size
When the user selects a different page-size option from the page-size selector
Then the table displays the selected number of rows per page
And the pagination controls update accordingly.

4b) Pagination - default page size

Given the audit trail table contains more rows than the current page size
When the user opens the System Audit Trail page for the first time
Then no page-size selection has been made
Then the table displays the default page size of 25 rows.

5) System audit trail data is not available

Given no system audit trail report is generated or available (ad hoc or via signoff) for the selected period
When the user opens the System Audit Trail page, selects a Month and Year from the dropdown lists (e.g. August, 2026) and clicks "Search"
Then a message is displayed to inform the user no audit trail data is available for the selected period.

6) Access restricted to administrators

Given the user does not have admin rights
When the user attempts to navigate to the System Audit Trail page
Then the page and its contents are not accessible to the user.
