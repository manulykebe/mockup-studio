JGVT-4462 - Reports_Audit Trail: Experiment Audit Trail - User Interface - Export Buttons - Acceptance Criteria

Scope: applicable only to Experiments using a GxP-GMP template (Release 3.0.0 and Release 3.1.0).

Preconditions

  • Given the user has an active Signals session
  • And the user opens an Experiment Audit Trail page containing data

1) Export options

Given the user is viewing an Experiment Audit Trail page containing data
When the user views the available actions
Then the user can see Copy, CSV, Excel, PDF and Print controls

2) Export content

Given the user is viewing an Experiment Audit Trail page containing data
When the user selects an export control
Then the complete audit trail dataset is copied, downloaded or printed in the user's selected format
And the output includes all records, not only the current page

3) Filtered export

Given the user has applied a filter to the audit trail
When the user selects an export control
Then the output contains all records matching the user's filter
And the user is informed that the output is a filtered subset

4) File name

Given the user is viewing an Experiment Audit Trail page containing data
When the user exports to CSV, Excel or PDF
Then the file is named {environment}.{experiment}.iso8601(creation date).experiment-audit-trail.{ext}
And {ext} is csv, xlsx or pdf

5) No data

Given the user is viewing an Experiment Audit Trail page with no audit trail data
When the user views the available actions
Then the export controls are disabled or unavailable

As a user,

I want to export the Experiment Audit Trail in different formats, so that I can save, share, print, or further process the audit information.

The export options shall be available from the Experiment Audit Trail page and shall support Copy, CSV, Excel, PDF, and Print. When the audit trail is filtered, the export shall contain the records matching the active filter.

Scope

  • Provide Copy, CSV, Excel, PDF, and Print export options.
  • Export all records when no filter is active.
  • Export only the matching records when a filter is active.
  • Inform the user when the export contains a filtered subset.
  • Use the filename format: {environment}.{experiment}.iso8601(creation date).experiment-audit-trail.{ext}

Out of scope

  • Custom Search Builder functionality.
  • Changes to sorting, pagination, or general table filtering.
  • Changes to the audit trail data source.
