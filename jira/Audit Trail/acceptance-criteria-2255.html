JGVT-2255 - Reports_Audit Trail: Experiment Audit Trail - User Interface - Filter - Acceptance Criteria

Scope: applicable only to Experiments using a GxP-GMP template (Release 3.0.0 and Release 3.1.0).

Preconditions (applies to all scenarios unless overridden)

  • Given the experiment uses a GxP-GMP template
  • And the user has an active Signals session
  • And the user navigates to the Experiment Audit Trail page for that experiment

1) Experiment audit trail data is available

Given the experiment has audit trail history
When the user opens the Experiment Audit Trail page
Then a table is displayed with columns: Date/Time, User Name, User ID, Entity Type, Entity Name, Action, Change Type, Details, Old Value, New Value, Event ID
And a global search field is displayed above the table
And sortable column headers show sorting arrows
And pagination controls (page numbers, previous/next, page-size selector) are displayed below the table
And the table is sorted by Date/Time ascending by default

2a) Search - matching records found

Given the audit trail table is displayed with data
When the user enters a search term that matches one or more rows
Then only the rows matching the search term are displayed
And the record count and pagination reflect the filtered result set

2b) Search - no matching records

Given the audit trail table is displayed with data
When the user enters a search term that matches no row
Then the table body is empty
And a notification "No matching records found" is displayed

3a) Sorting - ascending / descending per column

Given the audit trail table is displayed with data
When the user clicks a sortable column header
Then the table is sorted ascending by that column, indicated by the sort arrow
When the user clicks the same column header again
Then the table is sorted descending by that column, indicated by the sort arrow

3b) Sorting - multi-column

Given the audit trail table is already sorted by one column
When the user shift-clicks a second sortable column header
Then the table is sorted first by the initial column and then by the second column, both indicated by numbered sort arrows

3c) Sorting - disabled on non-sortable columns

Given the audit trail table is displayed with data
When the user looks at or clicks the header of a non-sortable column (Details, Old Value, New Value)
Then no sort arrow is shown for that column
And the row order does not change

3d) Sorting - default sort

Given the user opens the Experiment Audit Trail page and has not applied any sort
When the table loads
Then the table is sorted by Date/Time ascending by default

4a) Pagination - user page-size options

Given the audit trail table contains more rows than the current page size
When the user selects a different page-size option from the page-size selector
Then the table displays the selected number of rows per page
And the pagination controls update accordingly

4b) Pagination - default page size

Given the user opens the Experiment Audit Trail page for the first time
When no page-size selection has been made
Then the table displays the default page size

5) Experiment audit trail data is not available

Given the experiment has no audit trail history
When the user opens the Experiment Audit Trail page
Then a message is displayed to inform the user no audit trail data is available
And the search field, sorting arrows and pagination controls are not displayed
