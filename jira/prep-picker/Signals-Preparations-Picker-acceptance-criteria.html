User Story

As a User, I want to pick, reorder, link, and review preparations, materials, samples, and equipment in a unified split-screen interface,
So that I can establish accurate parent-child preparation dependencies, prevent circular references, and maintain complete traceability across experiment subtables.

Preconditions

  • Given the user has an active Signals session.
  • And the user opens an experiment containing a Preparation Master table and associated sub-entity tables (Preparations, Materials, Samples, Equipment).
  • And the user launches the Signals Preparations Selector interface.
  • And the Signals Preparations Selector replaces the existing preparation selector external action for these tables.

1) Split-screen layout and resizable divider

As a User, I need to adjust the workspace layout between the selector pane and details pane.
Given the user has opened the Signals Preparations Selector page
When the user drags the vertical split divider or uses the Left/Right arrow keys on the divider control
Then the width ratio between the left selector pane and right details pane adjusts dynamically between 20% and 80%
And table content within both panes resizes responsively.

2) Expandable and collapsible entity panels

As a User, I need to expand or collapse entity categories to focus on relevant data tables.
Given the user is viewing the selector pane containing panels for Preparation Master, Preparations, Material/Lot/Container, Samples, and Equipment
When the user clicks on any panel header
Then that panel toggles between expanded and collapsed states
And the panel header displays an entry count summary (e.g. "5 entries", "14 entries") and a visual chevron indicator.

3) Parent Preparation Master selection (Single and Multi-Select)

As a User, I want to select one or more parent Preparation Master records to manage their linked child items.
Given the user is viewing the Preparation Master table
When the user clicks a row selection checkbox without holding the Shift key
Then the selected record becomes the sole active parent preparation and any prior selection is cleared
When the user holds the Shift key and clicks additional row selection checkboxes
Then multiple Preparation Master records can be selected simultaneously.

4) Initial launch via external action and loading existing preparation content

As a User, I want to automatically load already defined compositions for each preparation when launching the interface.
Given an experiment containing a Preparation Master table and associated preparation, material, sample, and equipment tables
When the external action to trigger the Signals Preparations Selector is invoked for the first time
Then the system launches the selector interface and automatically loads the existing records, properties, current order, and links from those tables for each Preparation Master record
And the initial parent-child relationships and table selections are rendered accordingly.
When one or more required tables do not exist in the experiment
Then the user is informed that the required tables must be created before the selector can be used.

5) Asynchronous preparation details loading indicator

As a User, I need to receive visual feedback when preparation details are being retrieved.
Given the user selects or modifies a Preparation Master record selection for the first time
When preparation details are loading
Then an overlay loading modal with a spinner and the message "Loading Preparation Details" is displayed until loading completes
And once loading completes, the modal is hidden and the updated child item selections are displayed.

6) Automatic child record selection propagation

As a User, I want to see which child records belong to selected parent preparations.
Given one or more Preparation Master records are selected
When the user views the child tables (Preparations, Material/Lot/Container, Samples, Equipment)
Then child records linked to all currently selected parent preparations are displayed as selected
And child records linked to some (but not all) currently selected parent preparations are displayed as partially selected
And child records not linked to any selected parent preparation are displayed as unselected
And a child preparation that is the same record as a selected parent preparation cannot be selected.

7) Select individual or all visible child records

As a User, I want to select or deselect child records individually or all at once.
Given a child table contains multiple rows on the current page
When the user selects or deselects an individual enabled row, or selects or deselects all visible enabled rows
Then the affected records are linked to or unlinked from the active parent preparation(s)
And the records are added to or removed from the corresponding preparation's record list in the details pane.

8) Hover tooltips for linked child rows

As a User, I need to view which parent preparations are associated with a specific child record.
Given a child record is selected or partially selected
When the user hovers over the row selection control
Then a floating tooltip is displayed showing the Preparation ID, Name, and Comment for each parent preparation linked to that record.

9) Consolidated preparation details view in right pane

As a User, I want to review a consolidated list of all linked child records for each selected parent preparation.
Given one or more Preparation Master records are selected
When the user inspects the right details pane
Then a dedicated details block is rendered for each selected Preparation Master record
And each block contains a combined table listing all linked records from Preparations, Material/Lot/Container, Samples, and Equipment
And each row displays a source letter (P for preparation, M for material, S for sample, or E for equipment), ID, Name, and Comment
And rows within the combined table support sorting, search, and pagination.

10) Data table search, column sorting, and pagination

As a User, I want to filter, sort, and paginate through records across all tables.
Given any table contains data records
When the user enters a search term in the search input
Then only rows matching the search term across visible columns are displayed
When the user clicks a column header
Then the table sorts ascending or descending by that column based on data type
When the user selects a page size (5, 10, 25, All) or uses pagination buttons
Then the table updates the displayed records and updates the selection counter in the table info text (e.g. "Showing 1 to 5 of 14 entries - X selected").

11) Commit subtable updates

As a User, I want to save and commit updated preparation linkages back to the experiment session.
Given the user has configured parent-child preparation selections and child entity linkages
When the user clicks the "Update Prep. Sub" button
Then all parent-child associations and linked subtable records are saved and committed to the experiment dataset.

12) Recovery of uncommitted updates

As a User, I need to avoid losing uncommitted preparation updates if my browser session is reloaded or closed unexpectedly.
Given the user modifies parent-child selections or linkages in the selector interface
When changes are made prior to clicking "Update Prep. Sub"
Then the system temporarily stores the uncommitted working state for recovery
When the user opens or reloads the Signals Preparations Selector page
Then the system checks for pending uncommitted updates
And if non-committed updates are found, the system informs the user and restores the pending working state
And upon clicking "Update Prep. Sub" to commit the updates, the temporarily stored pending state is cleared.
