User Story

As a User, I want to pick, reorder, link, and review preparations, materials, samples, and equipment in a unified split-screen interface,
So that I can establish accurate parent-child preparation dependencies, prevent circular references, and maintain complete traceability across experiment subtables.

Preconditions

  • Given the user has an active Signals session.
  • And the user opens an experiment containing a Preparation Master table and associated sub-entity tables (Preparations, Materials, Samples, Equipment).
  • And the user launches the Signals Preparations Picker interface.

1) Split-screen layout and resizable divider

As a User, I need to adjust the workspace layout between the picker pane and details pane.
Given the user has opened the Signals Preparations Picker page
When the user drags the vertical split divider or uses the Left/Right arrow keys on the divider control
Then the width ratio between the left picker pane and right details pane adjusts dynamically between 20% and 80%
And table content within both panes resizes responsively.

2) Expandable and collapsible entity panels

As a User, I need to expand or collapse entity categories to focus on relevant data tables.
Given the user is viewing the picker pane containing panels for Preparation Master, Preparations, Material/Lot/Container, Samples, and Equipment
When the user clicks on any panel header
Then that panel toggles between expanded and collapsed states
And the panel header displays an entry count summary (e.g. "5 entries", "14 entries") and a visual chevron indicator.

3) Parent Preparation Master selection (Single and Multi-Select)

As a User, I want to select one or more parent Preparation Master records to manage their linked child items.
Given the user is viewing the Preparation Master table
When the user clicks a row selection checkbox without holding the Shift key
Then the selected record becomes the sole active parent preparation and any prior selection is cleared
When the user holds the Shift key and clicks additional row selection checkboxes
Then multiple Preparation Master records can be selected simultaneously.

4) Asynchronous preparation details loading indicator

As a User, I need to receive visual feedback when preparation details are being retrieved.
Given the user selects or modifies a Preparation Master record selection for the first time
When preparation details are loading
Then an overlay loading modal with a spinner and the message "Loading Preparation Details" is displayed for 5 seconds
And once loading completes, the modal is hidden and the updated child item selections are displayed.

5) Automatic child record selection propagation and tri-state checkboxes

As a User, I want to see which child records belong to selected parent preparations.
Given one or more Preparation Master records are selected
When the user views the child tables (Preparations, Material/Lot/Container, Samples, Equipment)
Then child records linked to all currently selected parent preparations are displayed with a checked checkbox
And child records linked to some (but not all) currently selected parent preparations are displayed with an indeterminate (tri-state) checkbox
And child records not linked to any selected parent preparation are displayed with an unchecked checkbox.

6) Select all visible rows in child tables

As a User, I want to select or deselect all visible child records at once.
Given a child table contains multiple rows on the current page
When the user ticks the "Select all visible" checkbox in the table header
Then all enabled visible rows on the current page are checked and linked to the active parent preparation(s)
When the user unticks the header checkbox
Then all visible enabled rows on the current page are unchecked and unlinked from the active parent preparation(s).

7) Hover tooltips for linked child rows

As a User, I need to view which parent preparations are associated with a specific child record.
Given a child record checkbox is in a checked or indeterminate state
When the user hovers the cursor over the row selection checkbox
Then a floating tooltip is displayed showing the Preparation ID, Name, and Comment for each parent preparation linked to that record.

8) Drag-and-drop and manual row number reordering

As a User, I want to reorder records either by dragging row handles or typing a specific row position.
Given a table is displaying all records on a single page (Page Length set to "All")
When the user drags a row handle to a new position in the table
Then the row is moved to the target position and all row numbers (#) update to 1..N order
When the user enters a numeric value into the "#" row number input field and presses Enter or leaves the field
Then the row is moved to the specified position and remaining rows are renumbered accordingly
And reordering controls are disabled when pagination hides records across multiple pages.

9) Circular reference prevention and warning notifications

As a User, I need to be prevented from creating circular preparation dependencies.
Given a row in the Preparations child table represents the selected parent preparation or would form a closed dependency loop (e.g. Prep A → Prep B → Prep A)
When the user inspects or attempts to select that preparation row
Then the row checkbox is disabled to prevent selection
And if a circular dependency is triggered, a warning toast notification (e.g. " ⚠ Circular reference: ...") is displayed at the bottom of the screen.

10) Interactive preparation relationship node graph panel

As a User, I want to visualize parent-child preparation relationships in a graphical diagram.
Given parent and child preparations exist in the session
When the user views the floating "Preparations Links" panel in the top-right
Then an SVG node graph renders all preparation records as circular nodes and dependency links as directed arrows
And selected parent preparations are highlighted in blue
And potential circular dependencies are displayed with red arrows
And the graph panel can be collapsed/expanded or repositioned across the viewport by dragging its header.

11) Consolidated preparation details view in right pane

As a User, I want to review a consolidated list of all linked child records for each selected parent preparation.
Given one or more Preparation Master records are selected
When the user inspects the right details pane
Then a dedicated details block is rendered for each selected Preparation Master record
And each block contains a combined table listing all linked records from Preparations, Material/Lot/Container, Samples, and Equipment
And each row displays a source icon (🧪, 📦, 🧬, 🔧), ID, Name, and Comment
And rows within the combined table support independent drag-and-drop reordering, manual row number input, sorting, search, and pagination
And manual row reordering in the details pane is preserved across subsequent selection changes.

12) Data table search, column sorting, and pagination

As a User, I want to filter, sort, and paginate through records across all tables.
Given any table contains data records
When the user enters a search term in the search input
Then only rows matching the search term across visible columns are displayed
When the user clicks a column header
Then the table sorts ascending or descending by that column based on data type
When the user selects a page size (5, 10, 25, All) or uses pagination buttons
Then the table updates the displayed records and updates the selection counter in the table info text (e.g. "Showing 1 to 5 of 14 entries - X selected").

13) Commit subtable updates

As a User, I want to save and commit updated preparation linkages back to the experiment session.
Given the user has configured parent-child preparation selections and child entity linkages
When the user clicks the "Update Prep. Sub" button
Then all parent-child associations, row orderings, and linked subtable records are saved and committed to the experiment dataset.

14) Data loss prevention via localStorage synchronization and pending update check

As a User, I need to avoid losing uncommitted preparation updates if my browser session is reloaded or closed unexpectedly.
Given the user modifies parent-child selections, linkages, or row orderings in the picker interface
When changes are made prior to clicking "Update Prep. Sub"
Then the system automatically synchronizes the uncommitted working state to browser localStorage
When the user opens or reloads the Signals Preparations Picker page
Then the system checks localStorage for pending uncommitted updates
And if non-committed updates are found, the system informs the user and restores the pending working state
And upon clicking "Update Prep. Sub" to commit the updates, the pending state in localStorage is cleared.
