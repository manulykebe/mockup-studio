# 60-second DataTables demo storyboard

## Purpose
Use this script to show that DataTables can turn any HTML table into an interactive experience. The current example is the Experiment Audit Trail, but the same approach works for any table.

## Suggested video structure

### 0-10s — Opening
- Visual: Show a plain HTML table, then transition to the styled DataTables view.
- Voice-over: "What looks like a simple HTML table can become a powerful, interactive experience."

### 10-25s — Search and sorting
- Visual: Type in the search box and click a column header to sort.
- Voice-over: "With DataTables, users can quickly search, sort, and find the exact records they need."

### 25-40s — Pagination and navigation
- Visual: Show page length selector and next/previous page controls.
- Voice-over: "Large datasets become easier to explore with paging, page-size options, and smoother navigation."

### 40-55s — Filters and export
- Visual: Highlight filters or export buttons, depending on the version shown.
- Voice-over: "The same pattern can also support filters and exports, turning raw data into something practical and ready to share."

### 55-60s — Closing
- Visual: End on the audit trail table with a polished DataTables layout.
- Voice-over: "That is why DataTables is a reusable solution for any HTML table, from audit trails to operational logs."

## Shorter voice-over version
"What looks like a simple HTML table can become a powerful, interactive experience. With DataTables, users can search, sort, and navigate large datasets with ease. The same approach can also support filters and exports, making raw data easier to explore and share. This is why DataTables is a reusable solution for any HTML table, from audit trails to operational logs."
